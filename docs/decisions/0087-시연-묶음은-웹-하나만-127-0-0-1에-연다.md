# 0087. 시연 묶음은 웹 하나만 127.0.0.1에 연다

- 날짜 / 관련 기능: 2026-10-29 / 보강 9(decisions/0084 결과·대가 "보강 9에서 포트를 바깥에 열지 않는다")
- 상황: 시연 도구(`apps/sandbox`)와 그 뒤의 가상 업체 서버·시뮬레이터에는 인증이 없다(0084). MySQL·Redis도 시연 비밀번호(.env)로 열린다. 개발 compose는 MySQL·Redis 포트를 모든 주소(0.0.0.0)에 연다.
- 선택지:
  1. **웹(nginx) 8080 하나만, `127.0.0.1:8080`에만** — 다른 컨테이너는 compose 네트워크 안에서만 부른다. 가상 업체·시뮬레이터는 nginx의 `sandbox.localhost` 아래 `/api/partners`·`/api/sim`으로만 닿는다
  2. 서비스마다 포트를 열기 — curl로 api·업체를 바로 부르기 편하다. 하지만 같은 네트워크의 누구나 시연 DB·장애 손잡이를 건드릴 수 있다
- 결정: 1. partners·device-sim은 컨테이너 안에서 `0.0.0.0`으로 듣는다(`PARTNERS_HOST`·`DEVICE_SIM_HOST`, 기본은 그대로 127.0.0.1 — 개발·테스트는 바뀌지 않는다). 외부 업체 API를 시연할 때는 웹 주소로 부른다(`http://developers.localhost:8080/api/partner/v1/...` — 시나리오 문서).
- 결과·대가: 개발 도구로 시연 DB를 직접 보려면 `docker compose -f docker-compose.demo.yml exec mysql mysql …`처럼 컨테이너 안으로 들어간다. 127.0.0.1에만 열려 같은 PC의 다른 사용자(공유 PC)는 막지 못한다 — 로컬 시연 전제.
- 다시 볼 조건: 시연을 남이 접속하는 곳(공유 서버·클라우드)에 올릴 때 — 시연 도구 앞에 인증, HTTPS(쿠키 Secure).
