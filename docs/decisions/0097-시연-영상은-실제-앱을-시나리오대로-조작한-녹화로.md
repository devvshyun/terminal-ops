# 0097. 시연 영상은 실제 앱을 시나리오대로 조작한 녹화로

- 날짜 / 관련 기능: 2026-10-30 / 보강 11 후속(0096의 영상 부분을 바꿈)
- 상황: 0096 배포본의 시연 영상은 시연 홈(제어판)의 자동 진행을 녹화한 것이었다. 사용자: "시연 영상이 왜 이래. 실제로 시나리오대로 실행을 하는 건데, 이건 그냥 시연 홈에서 버튼 몇 개 누른 것밖에 안 된다." 시연 영상에서 보여야 하는 것은 시스템을 쓰는 모습이다. 운영자가 어드민에서, 현장 작업자가 PDA에서, 점주가 매장 화면에서 시나리오(docs/demo.md)대로 일하는 장면이다. 제어판의 단추와 결과 패널은 그 모습이 아니다
- 선택지:
  1. **시연 묶음을 띄워 실제 앱을 조작한 녹화** — Playwright가 docs/demo.md 순서대로 각 앱에 그 역할로 로그인해 누르고 입력한다. 장점: 보는 사람이 실제 화면과 흐름을 본다, 시나리오 문서와 영상이 한 줄기다. 단점: 녹화에 약 10분이 걸리고 시연 묶음이 떠 있어야 한다, 화면이 바뀌면 선택자를 고쳐야 한다
  2. 사람이 직접 화면 녹화 — 장점: 자연스럽다. 단점: 다시 찍기 어렵다, 이 클라우드 컨테이너에서는 할 수 없다
  3. 0096 그대로(시연 홈 자동 진행) — 사용자가 거절
- 결정: 1. `scripts/record-demo-video.cjs`
  - 한 탭에서 앱을 오가며(호스트마다 쿠키가 따로라 역할별 로그인이 유지된다) 자막을 화면 아래에 그린다(누가 · 무엇을)
  - 누르는 곳은 잠깐 주황 테두리로 보인다
  - 기다리는 구간(택배 조회 429 재시도, 펌웨어 단계, 오프라인 판정)은 녹화 시각을 적어 두었다가 ffmpeg로 8배 빨리 감는다
  - 외부 업체 키 발급은 찍지 않는다(원문 키가 화면에 나온다)
- 결과·대가:
  - 시연 홈의 자동 진행(0095)은 영상의 원본이 아니게 됐다 — 시연 홈 안에서 "▶ 자동 진행" 단추로만 남는다
  - 영상을 다시 찍으려면 시연 묶음을 `down -v`로 비우고 띄워야 한다
- 배운 것: "시연"은 제품을 쓰는 모습이다. 시연을 돕는 도구(시연 홈·시연 도구)를 찍으면 시연이 아니다
