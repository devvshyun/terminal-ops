  ```
  table type   key                          rows  Extra
  m     const  terminal_model_code_unique   1     Using index; Using temporary
  r     ALL    NULL                         1     NULL
  i     eq_ref PRIMARY                      1     NULL
  t     eq_ref PRIMARY                      1     Using where
  ```
