| 4 | 세움 덜 보내기를 되돌리는 것이 발주 실패 때 빠진다 | 맞다 | `try/finally` |
| 5 | "다 했다" 표시(업체)를 키보다 먼저 만들어, 키에서 멈추면 다음 실행이 건너뛴다 | 맞다 | 업체와 키가 모두 있어야 건너뜀, 업체만 있으면 멈춤 안내(e2e: 키를 지우면 `도중에 멈춘` 오류) |

## 직접 확인한 것(이 클라우드 컨테이너)
- 이미지 넷 빌드(프록시 뒤라 `--build-arg HTTPS_PROXY`·`--secret id=ca`), `down -v` → `up -d --no-build` → demo-seed 끝까지 33초, `Exited (0)`
- 리허설: 시나리오 문서 1·3·5·6·9·10·11·12·13(업체 목록까지 — 키 발급은 보강 7 실서버 확인) 단계를 Playwright로(`*.localhost:8080`), 각 단계 결과는 devlog. 2(배송 완료 자동 전이)는 API로 확인. 4·7·8·14는 리허설하지 않았다(같은 화면이 다른 묶음 테스트로 덮여 있다)
- 바깥 포트: compose의 `ports`는 web `127.0.0.1:8080` 하나
- 비밀 값: 시드 스크립트는 키 원문을 출력하지 않는다(e2e가 본다). `.env`는 `.dockerignore`로 이미지에 들어가지 않는다(compose `env_file`로 실행 때만)
