# 보강 10 설계 — 시연 홈

- 날짜: 2026-10-30
- 범위: 시연 묶음(보강 9) 위에 "시연 홈" `apps/demo-home`(`demo.localhost:8080`, 개발 :5180). 시나리오 문서(`docs/demo.md`)를 화면으로 옮겨, 단계마다 **설명 + 실행 + 바로 옆 실제 결과**를 둔다
- 구현 계획: `docs/plans/2026-10-30-demo-home.md`
- 등장하는 회사·가맹점은 모두 가상이다

## 1. 무엇을 왜
지금 시연은 문서(14단계 표)를 옆에 띄워 두고 화면 일곱을 오가며 손으로 따라간다. 무엇을 누르면 백엔드가 어떻게 반응하는지(429 재시도, 배포 자동 중단, 오프라인 판정)가 이 시스템의 강점인데, 시연자가 화면 사이를 오가는 동안 흐름이 끊긴다.

레퍼런스(사용자 조사, 2026-10-30):
- 장애 시연 앱(OpenTelemetry 데모의 기능 플래그 화면, Istio·Linkerd 장애 주입): **정상 → 장애 켜기 → 반응 → 되돌리기**를 한 묶음으로
- 개발자 실행 시연(Stripe Shell): **설명 문단 + 실행 단추 + 바로 옆에 실제 응답**
- 대화형 시연(Navattic류): **짧은 흐름과 진행률**(막마다 3~5단계)
- 페르소나 시연(Temporal 예제): 역할 사이를 넘기며 같은 일을 따라간다

## 2. 화면
- 위: 시연자 로그인(운영자 `operator` — decisions/0092), 진행률(끝낸 단계 수/전체), "처음 상태로"(진행 표시만 지움 — 데이터는 `down -v`)
- 왼쪽: 7막 목록(막마다 진행률). 가운데: 고른 막의 단계 카드
- 단계 카드: 번호 · 누가(역할) · 설명 · [실행] 또는 [화면 열기 ↗] · 결과 패널(실제 API를 읽어 보이고, 기다리는 단계는 몇 초마다 다시 읽는다) · "끝냄" 표시

| 막 | 이야기 | 단계 |
|---|---|---|
| 1 한눈에 | 운영자가 처음 화면을 연다 | 처음 화면 숫자(대시보드) · 이상 단말기 두 대 |
| 2 공장에서 창고로 | 세움전자 납품 → 현장 스캔 → 입고 대조 | 납품 명세 보기 · 현장 박스 스캔(화면 열기, 입고 수를 다시 읽음) · 대조·마감 |
| 3 가맹점까지 | 배정·출고 → 택배 수집 → 점주 홈 | 재고 한 대 배정·출고(번개택배) · 배송 완료 기다리기 · 매장 화면 열기 |
| 4 고장과 교체 | 점주 접수 → 원격 점검·교체 출고 | 매장에서 접수(화면 열기, 접수 목록을 다시 읽음) · 원격 점검 → 교체 출고 · 점주 설치 확인 |
| 5 택배사가 429를 낸다 | 정상 → 429 켜기 → 출고 하나 → 재시도 → 되돌리기 | 최근 택배 수집 · 429 50% 켜기 · 출고 하나 · 반응(429·다시 시도) · 0으로 되돌리기 |
| 6 펌웨어 배포와 자동 중단 | 정상 배포 → 실패율 켜기 → 자동 중단 → 되돌리기 | 새 버전 배포 · 실패율 60% · 다른 새 버전 배포 → 자동 중단 · 실패율 0 |
| 7 단말기가 끊긴다 | 끄기 → 오프라인 판정·알림 → 켜기 | DM-0005 끄기 · 오프라인과 톡톡 알림 기다리기 · 켜기 |
| 끝 | 다른 화면 | 운영 관제 · 개발자센터 · 시연 도구 링크 |

- 재고가 없으면(막 3·4·5를 여러 번 돌려) 시연용 재고 한 대를 실제 API로 만든다(등록 → 검수 합격 → 재고)
- 새 버전은 펌웨어 목록을 보고 쓰지 않은 다음 버전(1.3.0, 1.4.0 …)을 고른다(같은 버전 재배포는 시간 제한까지 기다린다 — troubleshooting/0021)

## 3. 하지 않는 것
- api 변경(필요한 읽기·쓰기가 모두 운영자 권한으로 있다)
- 각 앱 위에 말풍선(Driver.js) — 각 앱에 들어가는 일이라 다음 묶음 후보
- 진행 상태를 서버에 남기기(이 브라우저의 localStorage만 — 지워져도 시연은 된다)

## 4. 검증
- Vitest: 로그인 문, 막·단계 그리기, 실행 단추가 부르는 API(배정·출고·429 켜기·배포·끄기)와 결과 패널, 재고 없을 때 만들기, 다음 버전 고르기, 진행률
- 시연 묶음에서 Playwright로 7막을 시연 홈에서만 끝까지(화면 열기 단계는 그 앱에서 한 동작만)
