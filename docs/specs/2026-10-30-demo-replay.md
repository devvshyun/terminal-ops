# 보강 11 스펙: 시연 홈 녹화 재생본(GitHub Pages)

> 결정 0093(녹화 재생으로 Pages에), 0094(녹화 시계). 제작 과정은 `docs/making/2026-10-30-demo-replay.md`.

## 1. 목표
- 서버 없이 링크 하나로 시연 홈 7막을 눌러 볼 수 있다(GitHub Pages)
- 보이는 숫자·글은 모두 시연 묶음이 실제로 낸 응답이다(꾸며 낸 응답 없음)
- 보통 시연 홈(시연 묶음의 `demo.localhost:8080`)은 그대로 — 재생 코드는 재생본에서만 켜진다

## 2. 녹화
- 시연 묶음을 `down -v`로 비우고 띄운 직후, Playwright가 시연 홈 7막을 리허설 순서대로 진행한다
- 시연 홈 밖에서 하는 일도 실제로 한다: 현장 박스 스캔(현장 화면), 점주 고장 접수·설치 확인(매장 화면)
- 남기는 것
  - 시연 홈이 받은 `/api` 응답(시각·방법·경로·상태·본문). 같은 GET 경로는 본문이 바뀔 때만
  - 실행마다 단계 key·단추 글자·누른 때·끝난 때
  - 다른 화면 사진(화면 열기 단추가 가리키는 앱·경로, 찍은 시각)
- 남기지 않는 것: 요청 본문, 쿠키, 헤더, 로그인·로그아웃 응답. 다 쓴 뒤 시연 비밀번호가 녹화본에 있으면 쓰지 않고 멈춘다

## 3. 재생
- 녹화 시계(0094): 다음 실행 앞에서 멈춤 → 실행을 누르면 그 시각으로 → 끝나면 다음 실행까지 8배속
- 화면에서 달라지는 것
  - 로그인 칸 자리에 녹화 시계(mm:ss, "다음 실행을 기다림" / "8배속으로 흐르는 중")
  - 위 막대 아래 녹화본 안내 띠(녹화 시각, 직접 돌리는 길)
  - [화면 열기 ↗] → 녹화 사진(지금 녹화 시각 이전의 마지막 사진)
  - 같은 실행을 녹화한 횟수보다 더 누르면 안내, "처음 상태로"가 녹화 시계도 되돌린다
- 주소는 해시(`#/act/3`) — Pages는 모르는 경로를 index.html로 돌려주지 않는다

## 4. 배포
- `.github/workflows/pages.yml`: master에서 `apps/demo-home/**`가 바뀌면 테스트 → `npm run build:replay` → Pages
- 처음 한 번 저장소 Settings → Pages → Source를 "GitHub Actions"로(사람이)

## 5. 범위 밖
- 녹화본 자동 갱신(CI에서 시연 묶음 띄우기)
- 다른 앱(어드민·매장 화면)의 재생본 — 사진으로 대신한다
