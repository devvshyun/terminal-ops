# 0001. 설치 직후 WSL2·Docker가 동작하지 않음

- 날짜 / 관련: 2026-10-22 / 인프라(Day 0)
- 증상: `wsl --install`, `winget install Docker.DockerDesktop` 후에도 `docker` 명령 없음. `wsl --status`가 "가상 머신 플랫폼이 활성화되지 않았거나 BIOS 가상화가 꺼져 있어 WSL2를 실행할 수 없다"고 출력
- 가설:
  1. BIOS에서 CPU 가상화가 꺼져 있다
  2. Windows 기능(가상 머신 플랫폼)이 재부팅 전이라 아직 적용되지 않았다
- 확인:
  - `Win32_Processor.VirtualizationFirmwareEnabled` = True → 가설 1 기각 (BIOS 진입 불필요)
  - `Win32_ComputerSystem.HypervisorPresent` = False, 마지막 부팅 2026-10-14 → 설치 후 재부팅 안 됨. 가설 2 유력
- 해결: 재부팅(크롬 원격 데스크톱으로 재접속). 재부팅 후 `HypervisorPresent` = True, `docker-desktop` WSL2 배포판 생성, Docker Engine 정상
- 덤: 설치 중 PowerShell에 `[O` 제어 문자가 붙어 파서 오류(`EndSquareBracketExpectedAtEndOfAttribute`) → 직접 타이핑으로 해결
- 배운 것: Windows 선택 기능은 재부팅해야 적용된다. "BIOS 문제"로 단정하기 전에 펌웨어 가상화 값과 하이퍼바이저 존재 여부를 따로 확인하면 원인이 갈린다.
