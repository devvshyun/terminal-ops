# 0026. 실제 시각과 고정 시각이 섞인 테스트가 날짜가 지나 실패

- 날짜 / 관련 기능: 2026-10-27 / F4 (테스트)
- 증상: Day 6 Task 1 시작 때(브랜치 `day6-admin`, HEAD fffceff — api 코드는 master 6085a2a와 같음) `npx vitest run test/anomaly.e2e.spec.ts`:
  ```
  FAIL  test/anomaly.e2e.spec.ts > 이상 단말기 찾기 (F4, decisions/0034) > fix 3: 겹친 찾기 중 늦게 쓰는 쪽의 시각이 더 이르면 last_seen_at을 뒤로 돌리지 않는다(INSERT 겹침·계속 갱신 둘 다)
  AssertionError: expected [ [ 3, true, 1793067954271 ], …(1) ] to deeply equal [ [ 3, true, 1793008801000 ], …(1) ]
  -     1793008801000,
  +     1793067954271,
   ❯ test/anomaly.e2e.spec.ts:260:109
   Test Files  1 failed (1)
        Tests  1 failed | 10 passed (11)
  ```
  어긋난 것은 첫 행(terminalId 3 = AN-03, 앞 테스트부터 열린 RETURN_STALLED)의 `last_seen_at`뿐이고, 둘째 행(AL-01)은 기대값과 같았다. Day 5 최종 검증(2026-10-26 오후)에서는 통과했다. 계획 문서는 이 파일을 13개로 적었지만 실제로는 11개다(실패 1개는 같다).
- 가설:
  1. 이상 찾기 코드가 바뀌었다.
  2. 테스트 순서가 바뀌었다.
  3. 앞 테스트가 실제 시각으로 쓴 값이 고정 시각 기준의 기대값보다 커졌다.
- 확인:
  - `git log -- apps/api`의 마지막 커밋은 4601564(10-26 15:31), 그 뒤로는 docs·머지뿐이다 → Day 5 최종 검증 뒤 코드 변경 없음, 가설 1 기각. vitest는 한 파일 안의 테스트를 적힌 순서대로 돌리고 파일도 바뀌지 않았다 → 가설 2 기각.
  - `node -e "console.log(new Date(1793067954271).toISOString())"` → `2026-10-27T02:25:54.271Z`(테스트를 돌린 바로 그 시각). `node -e "console.log(new Date(1793008801000).toISOString())"` → `2026-10-26T10:00:01.000Z` = `NOW(2026-10-26T00:00Z) + 10시간 + 1초`(테스트의 t2).
  - `grep -n "POST /anomaly-scans" test/anomaly.e2e.spec.ts` → 134행 `POST /anomaly-scans: 수동 찾기(지금 시각) …`. 이 앞 테스트가 실제 지금 시각으로 찾기를 돌려 AN-03(열린 채 이어지는 RETURN_STALLED)의 `last_seen_at`을 실제 지금으로 쓴다. fix 3의 늦은 쓰기는 `greatest(last_seen_at, ?)`라 더 큰 실제 시각이 남는다 → 가설 3 확인. 실제 시각이 2026-10-26T10:00Z(19:00 KST)를 넘은 뒤로는 늘 실패한다.
- 원인: 한 파일 안에서 실제 시각(`new Date()`)을 쓰는 테스트와 고정 시각(`NOW`)을 쓰는 테스트가 같은 행을 공유했다. 코드 문제가 아니라 테스트의 시간 가정이다.
- 해결: fix 3의 t1을 `max(NOW, 실제 지금) + 10시간`으로 바꿨다(항상 앞 테스트가 쓴 값보다 뒤). (리뷰 반영 정정) 앞 테스트에 대한 의존을 없앤 것이 아니다 — 두 테스트는 여전히 AN-03 행을 공유한다. "fix 3이 쓰는 시각은 앞 테스트가 쓴 실제 시각보다 항상 뒤"라는 단조 불변식으로 바꿔, 날짜가 지나도 깨지지 않게 했을 뿐이다. 근본 대안(앞 테스트가 만든 단말기를 fix 3이 쓰지 않게 격리)은 backlog에 남겼다. 다른 기대값(AL-01의 상태 경과)은 NOW 기준 20일 전이라 영향 없다. 고친 뒤 `npx vitest run test/anomaly.e2e.spec.ts test/weekly-report.e2e.spec.ts` 통과. 커밋은 devlog 2026-10-27의 Task 1 항목.
- 배운 것: 실제 시각과 고정 시각을 섞는 테스트는 "언젠가 실패"한다 — 같은 데이터를 공유하면 한쪽으로 통일하거나 기준을 둘 중 큰 값으로 → study/backlog.md
