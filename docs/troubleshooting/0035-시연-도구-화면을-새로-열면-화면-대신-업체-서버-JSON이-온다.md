# 0035. 시연 도구 `/partners`를 새로 열면 화면 대신 업체 서버의 JSON이 온다

- 날짜 / 관련 기능: 2026-10-29 / 시연 도구(`apps/sandbox`, decisions/0084)
- 증상: 최종 검토가 지적했다 — Vite 프록시 앞마디 `/partners`가 화면 경로 `/partners`와 같다. 확인하니 `curl -H 'Accept: text/html' localhost:5179/partners` → `{"error":"NO_ROUTE","method":"GET","path":"/"}`. 업체 서버 요청 기록에도 `partner: ''`, `path: '/'` 줄이 쌓여 있었다(화면을 열 때마다)
- 왜 화면 확인에서 못 봤나: Playwright 확인은 `/`로 들어가 화면 안 링크(클라이언트 이동)로 `/partners`에 갔다 — 서버를 거치지 않는다. 휴대폰 폭 확인은 `goto('/partners')`로 새로 열었는데 `scrollWidth`만 세고 사진을 보지 않았다(JSON 글자 화면의 폭이 390이었다). 어드민 "다른 화면" 링크는 바로 이 주소를 새 탭으로 연다
- 원인: Vite 개발 서버의 프록시는 경로가 앞마디로 시작하면 받는 형식(`Accept`)과 상관없이 넘긴다(`bypass`를 주지 않으면). 프록시가 SPA 기본 문서(index.html)보다 먼저다
- 해결: 앞마디를 `/api/partners`·`/api/sim`으로(화면 경로와 겹치지 않는다). `App.test`가 (1) 모든 요청이 `/api/` 아래인지, (2) `vite.config.ts`의 프록시 앞마디와 화면 경로가 서로의 앞부분이 아닌지 본다. 고친 뒤 `curl -H 'Accept: text/html' localhost:5179/partners` → `<title>단말온 시연 도구</title>`, 업체 기록에 이름 없는 줄 0
- 배운 것: 화면 확인은 "주소를 새로 열기"와 "사진을 본다"까지 해야 한다. 수만 세면 엉뚱한 화면도 통과한다 → study/backlog.md
