# 0037. 시연 4단계 번개택배 429를 켜도 아무것도 안 보인다

- 날짜 / 관련 기능: 2026-10-30 / 보강 9(시나리오 docs/demo.md), F3 택배 수집
- 증상(로컬 컨트롤러 리허설, 받아 적은 것): 4단계에서 번개택배 "429 확률" 50%를 적용했는데 그때는 최근 요청에도 배치 실행 이력에도 변화가 없었다. 7단계에서 DM-0014를 번개택배로 출고한 뒤에야 배치 실행 #62가 ERROR `PartnerRateLimitedError … 429`, #63(attempt 2) OK로 보였고 운영 관제 "최근 오류"에 429가 떴다.
- 가설: 1) 손잡이가 적용되지 않았다 2) 그 시점에 추적할 운송장이 없다
- 확인: `carrier-sync.service.ts:49`는 `ShipmentStatus.IN_TRANSIT`인 운송장만 조회한다. 이 컨테이너에서 묶음을 띄우고 api가 뜬 지 약 1분 30초 뒤 DM-0013·0019·0020 모두 `DELIVERED`(admin 호스트 `/api/terminals/DM-…`). 7단계 출고 뒤 429가 바로 보인 것(받아 적은 것)은 손잡이가 적용돼 있었다는 뜻 → 가설 1 기각, 2 확인
- 원인: 시연 데이터의 배송이 띄우고 1~2분이면 모두 끝나고(시연 compose `SWEEP_INTERVAL_MS=15000`), 4단계쯤이면 택배 추적 호출이 0이다. 시나리오 순서 문제다(코드는 설계대로).
- 해결: `docs/demo.md` 순서를 바꿨다 — 429 켜기를 6번으로 옮겨 7번 출고(번개택배, 기본값) 바로 앞에 두고, 보이는 것을 7번에 적었다. "모두 기본값으로"가 아니라 0으로 되돌리는 안내는 그대로. 커밋 = 이 기록이 든 커밋
- 배운 것: 시간이 지나면 사라지는 상태(배송 중)에 기대는 시연 단계는 그 상태를 직접 만드는 단계 바로 뒤에 둔다.
