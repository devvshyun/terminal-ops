# 0039. 시연 홈에서 로그인해도 결과 패널이 로그인 전 401을 그대로 보인다

- 날짜 / 관련 기능: 2026-10-30 / 시연 홈(`apps/demo-home`, decisions/0092)
- 증상: 시연 묶음 리허설(Playwright)에서 시연 홈을 열고 운영자로 로그인했는데, 1막 "처음 화면 숫자"·"이상 단말기" 패널이 "로그인이 끝났습니다 … (UNAUTHENTICATED)"를 그대로 보였다. 다른 막으로 갔다 오면 숫자가 나왔다
- 가설: 1) 로그인 쿠키가 시연 홈 호스트에 안 붙는다 2) 로그인 뒤 다시 읽지 않는다 3) 다시 읽는데 캐시가 비워져 화면에 닿지 않는다
- 확인:
  - 1: 다른 막의 패널은 로그인 뒤 처음 열 때 숫자가 나왔다 → 쿠키는 붙는다. 기각
  - 2·3: 로그인 성공 때 `invalidateQueries(keys.all)`를 더한 뒤에도 테스트가 실패했다(`Unable to find an element with the text: 운영 중 12 · 온라인 11 · 오프라인 1`). 점주 앱 사본 `SessionCacheSync`는 로그인한 사람이 바뀌면 `client.clear()`로 캐시를 통째로 비운다 — 이미 떠 있는 `useQuery`는 비워진 쿼리를 다시 구독하지 않아 오류 상태를 들고 있고, 비운 캐시에는 무효화할 쿼리도 없다
- 원인: 다른 화면 앱은 로그인하면 다른 경로로 넘어가 화면이 새로 마운트돼 문제가 안 보였다. 시연 홈은 로그인 상자가 위 막대에 있어 로그인해도 같은 화면이 그대로 떠 있다
- 해결: 로그인한 사람이 바뀌면 가운데(`<main>`)를 그 사람 아이디로 key를 줘 새로 그린다 — 패널이 처음부터 다시 읽는다. `SessionCacheSync`(사본)는 그대로 둔다(사본 검사, 0062). 대가: 그 순간 화면 상태(불러 둔 납품 시리얼 등)도 사라진다 — 사람이 바뀌는 순간이라 받아들인다. 테스트 먼저(`Tests  1 failed`) → 통과, key를 빼면 다시 실패하는 것도 확인. 시연 묶음에서 로그인 전 401 → 로그인 뒤 "운영 중 11 · 온라인 10 · 오프라인 1"
- 배운 것: `QueryClient.clear()`는 떠 있는 관찰자에게 알리지 않는다(`resetQueries`는 알린다) → study/backlog.md
